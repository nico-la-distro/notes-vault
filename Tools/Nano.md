## **Hotkeys**

| Raccourci                     | Description / Utilité                                          |
| ----------------------------- | -------------------------------------------------------------- |
| **Ctrl+O**                    | Sauvegarder le fichier actuel                                  |
| **Ctrl+X**                    | Quitter Nano (demande de sauvegarde si non fait)               |
| **Ctrl+R**                    | Insérer un fichier dans le fichier courant                     |
| **Ctrl+G**                    | Afficher l’aide / liste complète des commandes                 |
| **Ctrl+W**                    | Rechercher un texte dans le fichier                            |
| **Alt+W**                     | Rechercher la prochaine occurrence (après Ctrl+W)              |
| **Ctrl+\ **                   | Rechercher et remplacer un texte                               |
| **Ctrl+_**                    | Aller à une ligne et colonne spécifique                        |
| **Ctrl+K**                    | Couper le texte sélectionné ou la ligne entière                |
| **Alt+6**                     | Copier le texte sélectionné                                    |
| **Ctrl+U**                    | Coller le texte précédemment coupé ou copié                    |
| **Alt+A**                     | Marquer le début d’une sélection de texte                      |
| **Ctrl+6**                    | Annuler la sélection de texte                                  |
| **Ctrl+J**                    | Justifier le paragraphe courant                                |
| **Ctrl+C**                    | Afficher la position du curseur (ligne, colonne, caractères)   |
| **Ctrl+T**                    | Vérifier l’orthographe (si dictionnaire installé)              |
| **Ctrl+_ suivi d’un numéro**  | Aller directement à une ligne précise                          |
| **Alt+X**                     | Fermer un fichier sans quitter Nano (peut demander sauvegarde) |
| **Alt+R**                     | Lire un fichier dans le buffer actuel                          |
| **Ctrl+L**                    | Rafraîchir l’écran                                             |
| **Alt+Shift+U / Alt+Shift+D** | Transformer le texte sélectionné en majuscules / minuscules    |
